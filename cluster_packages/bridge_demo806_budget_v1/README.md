# 806演示：一次有界训练预算对照

独立于已收尾的208207固定8192预算实验。数据、模型、损失、seed42、batch8、前8192采样与学习率均不变，只增加7978次低学习率更新，总数16170。前4096次1e-4，其余1e-5；不是将降学习率时点挪到总预算的一半。

因208207只保存了权重而没有Adam动量，正式入口必须重建其前8192次更新。在8192处核对全部损失、模型参数、旧4窗上下文/预测，门槛分别1e-5、1e-5、1e-4、1e-4；不一致就停止，不用重设Adam代替连续训练。重建不是新的405参照训练，不重做8192处的完整训练/开发集评价。数据、CLIP缓存与原208194预检证据复用。缺少完整缓存则立即停止，不重新编码。

后7978批继续同任务窗口洗牌流；任务标签重复旧表的前7978批，前8192批逐项完全相同。每窗平均访问18.08→35.695次，接近旧405池的35.695次；各窗并非同次数。这轮检验同806池的额外低学习率优化收益，不把它称为保持单窗曝光完全相同的数据量因果实验。

预检检查完整旧输入/缓存、208207冻结模型旧4窗重放、前后边界抽样及实际Adam保存/恢复后4次连续更新完全一致。共12次运行更新，不训练到8192，不评分新候选开发集，不以拟合门槛决定是否正式。其逻辑更新编号8189—8196不等于真的完成8196次训练，报告明确记录实际12次优化。

正式保存8192和16170处模型+Adam+RNG（各小于2GiB）及最终模型（小于1GiB），只留集群。新增加容量规划5GiB，并在200GiB规划上限下保留15GiB余量；du不是实时配额查询。无新数据包、下载、缓存、原E盘修改或本地项目模型运行。

正式只在16170处评价全3624训练窗及原10开发演示/40窗。主要比较16170与208207的窗口等权、演示等权路径位置/旋转四均值，均不高于且至少一项更低才认为有开发集整体收益；训练误差仅诊断。报告所有任务和演示，不挑样本。新25预留测试不在入口读取或评分；获得后续独立验收资格还需同时不劣于405参照，且四均值低于同批静止。

一次固定端点后停止，不自动继续加更新、换种子或扫参数。若训练改善而开发无整体收益，结论是这次有限追加未解决泛化，不能推断所有预算均无效，也不宣称唯一根因已找到。
