# 单项训练图像增强对照

目标是独立演示泛化，训练误差仅作检查。冻结协议见protocol.json。

成功PushT权重采用96图像上的84随机裁剪、评估固定裁剪。Bridge作者迁移参照关闭了裁剪，项目也一直缓存固定观察特征。本轮借鉴训练随机、评估固定的原则，适配CLIP224输入：边缘复制填充8像素，每次训练随机移回224。它不是论文裁剪的精确复现，也不是已证实的根因。

保留逐样本图像、语言、真实当前状态及原标签。冻结CLIP在线编码增强图像；评估复用原图token。重复当前观察的两次Adapter调用共用同一次增强。批次、噪声种子、初始化、模型、128/40划分、8192更新及学习率与202278一致，旧控制不重跑。

先运行preflight.sh，仅16次入口更新及四个已见训练窗检查；不评价开发集，不要求达到毫米拟合。检查在线中心编码、RNG隔离、恢复一致、冻结CLIP和资源。通过后再提交一次fit.sh，传入AUG_PREFLIGHT_JOB。正式只看原40开发位置和旋转及逐演示/任务结果；不追加预算或增强强度。

复用现有环境、模型、数据与完整原图缓存；不安装、不下载、不保存多视图缓存。本地检查不执行正式训练，最终PT留集群。
