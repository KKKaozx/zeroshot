# Configuration records

`bridge_full_x0/` stores actual exported provenance, experiment metadata and the
original episode split for the completed full-training-set diagnostic.
Historical runnable argument chains are in `../experiments/`; inspect nested
`@...args` files and update local paths/output directories before reuse.

`baseline.example.yaml` belongs to the initial repository plan. It is an example,
not the configuration that generated the published Bridge results, and it is not
evidence of an integrated VLA-Adapter/LIBERO baseline.
