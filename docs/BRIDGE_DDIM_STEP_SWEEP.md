# Bridge冻结权重DDIM步数对照

准备日期：2026-10-08。193030已证明同一192651扩散模型在最高噪声处的一步x0读出明显优于保存的100步随机DDPM，但仍弱于回归。本实验固定该权重、数据窗口与三个初始噪声，比较1、2、4、8、16、32、50和100次U-Net评估的确定性DDIM（`eta=0`），不重新训练。

每个步数使用从`t=99`到`t=0`的均匀递减离散时间表；一步即193030的`t=99`直接x0读出。每步使用网络预测的x0和由当前状态反推的噪声构造下一选定时间状态，并沿用训练模型的分量裁剪，最终使用生产位姿约束与夹爪解码。一步结果必须逐指标精确重放193030，否则作业失败。

报告覆盖完整1836个训练窗口和40个开发窗口，包含路径、第16目标、夹爪事件、逐任务及逐演示指标。保存的100步随机DDPM与回归预测仅作为只读对照。该开发集可用于确定下一轮采样协议，但不是保留测试或仿真成功率；确定性DDIM也是对DDPM训练权重的推理消融。

入口：[评估脚本](../code/evaluate_bridge_ddim_steps.py)与[集群脚本](../scripts/cluster/bridge_ddim_steps.sh)。
