# Bridge仅替换视觉骨干的对照

用户已明确提出控制变量，仅把CLIP改为DINO。以原207558为历史CLIP对照，新增一个从相同初始化开始的冻结DINOv2 ViT-L/14候选；不重训原CLIP，也不把当前OXE多来源模型拿来比较骨干因果影响。

固定1836训练窗/405演示、40开发窗/10演示，原8192×8批次日程和seed42，当前9维位姿状态支路、CLS+patch均值读出、sample/x0目标、原工具相对坐标、裁剪上界3、冻结夹爪、多尺度后端、DDPM100与3个采样种子，Adam前4096步1e-4/后4096步1e-5。唯一处理变量为冻结视觉编码器及其必需通道归一化；文本编码器/特征、图像几何处理不变。

新包保留旧runner/core原字节。新的输入帮助函数从真实原始记录恢复全部1876输入，逐项要求图片、目标、当前夹爪、当前位姿特征和415记录payload与207558相同；直接复用原1876缓存中的文本特征。DINO加载用RNG隔离，原下游初始化/完整可训练参数数目必须匹配旧摘要；DINO替换只在原模型构造后发生。配置显式保存新骨干身份，避免把新权重误当CLIP模型。

默认要求旧同款A6000、Torch2.5.1+cu118；不自动换成A40。旧完整CLIP缓存或原始分片缺失时停止、列出路径，不盲目下载或重建大数据包。包中不含图像/模型权重，仅约1MB；集群另建一次约2GB DINO特征缓存，之后正式复用。

先由用户提交一次完整输入/缓存短预检，原16次工程更新验证支路与恢复，只查4个训练探针，不看开发结果；其学习权重废弃。新正式DINO从fresh seed42开始，且只允许8192次更新，不据结果延长、追加seed或改读出。正式前逐份核验新预检与合同，绝不自动提交。原主OXE模型和大评估暂停状态保留。
