# Bridge轨迹终点与操作事件评估

准备日期：2026-10-08。此项只读取192651已经保存的回归与扩散预测数组，不加载权重、不重新推理、不训练。目的是补充逐点平均误差，判断扩散是否存在“路径与演示不同但第16个目标正确”的情况。

当前动作块包含16个目标，每个目标都相对于输入图像时刻的同一个末端执行器坐标系编码，并非相邻目标之间逐步累加。因此第16个目标可以直接比较位置和旋转，但它只是预测窗口的终点，不一定是完整机器人任务的最终状态。

报告同时计算：

- 16个目标的平均位置和旋转误差，作为ADE形式的路径指标；
- 第16个目标的位置、旋转和夹爪状态误差，作为FDE形式的窗口终点指标；
- 真值动作块内部打开到关闭、关闭到打开事件在目标`t+1`处的位姿误差，以及模型是否在完全相同的时间对发生切换；
- 不移动、训练任务均值、回归和扩散的相同分组结果；
- 对扩散保存的三个样本，报告逐样本结果和每窗口看过真值后分别挑选最小误差的oracle best-of-3。

best-of-3只表示采样分布是否覆盖较好轨迹。位置路径、位置终点、旋转路径和旋转终点分别选择最佳样本，可能不是同一条轨迹；部署时没有真值，若没有额外评价器就不能选择它，因此不得作为实际策略性能。

操作事件只统计16个目标内部相邻状态的切换，不包含输入时刻当前夹爪到第一个目标的变化，数量与此前离线切换对一致。事件位置误差使用真值事件时间，不表示模型预测了正确切换；切换准确率另行报告。

离线终点与事件指标仍不能检验碰撞、路径可执行性、是否操作正确物体、物体状态或闭环纠错。导师要求的每任务100次仿真任务成功率仍是最终主要指标。当前先用该小型CPU作业判断扩散失败位于整条路径还是也包括窗口终点；夹爪切换与控制接口通过前不进入仿真。

入口：[评估脚本](../code/evaluate_bridge_endpoint_metrics.py)及[集群脚本](../scripts/cluster/bridge_endpoint_metrics.sh)。

## 192939结果

CPU作业在1秒内完成，Slurm状态COMPLETED、退出码0:0。完整报告与192651训练报告、191004窗口清单的哈希匹配；回归和扩散数组形状分别为`[1,1876,16,8]`和`[3,1876,16,8]`。16目标平均指标与192651原报告在浮点容差内逐项一致。没有训练、加载权重或读取保留测试目标。

普通扩散的第16目标误差也高于静止，不能用“中间路线不同但终点正确”解释主要失败。回归在五个任务的第16目标位置均优于扩散三样本平均；10条开发演示中也是10/10。回归第16目标位置只在6/10条演示优于静止，说明开发样本仍有明显困难，不能把总体改善写成全面成功。

oracle说明三个扩散样本中存在较好覆盖：开发路径旋转12.158°接近回归12.108°，第16目标9.362cm/15.018°也优于静止。但oracle每窗口看真值并且各标量可以选择不同样本；它在10条开发演示中只有4条第16目标位置优于回归，不能作为部署策略。微波炉第16目标位置即使oracle仍为13.581cm，关抽屉为12.133cm，分别差于回归8.508cm与9.856cm。

真值操作事件处，回归开发抓取位姿6.905cm/10.099°，扩散三样本平均8.629cm/14.098°；释放为6.673cm/10.716°和11.590cm/17.155°。位姿改善没有解决事件时间：回归抓取3/20、释放0/8，扩散平均约2.7/20与0/8。事件指标只涉及窗口内部真值切换，不代表实际抓住或释放物体。

结论仍以闭环任务成功率为最终标准。当前证据支持继续改进扩散训练与可部署采样选择，而不是删除扩散或只改离线评分；同时必须单独修复夹爪事件。原始证据：[完整报告](../reports/bridge-endpoint-192939.json)；来源核对和精简结果：[摘要](../reports/bridge_endpoint_192939_verified_summary.json)。
