# Bridge epsilon冻结权重步数核对

准备日期：2026-10-08。193195只改变训练目标为epsilon后，8步DDIM在训练与开发上都明显差于x0一步、回归和静止。为避免把“8步不适合当前小网络”误判为“epsilon监督完全无效”，本实验复用193195最终权重，比较8、16、32、100步确定性DDIM，不训练或更新权重。

评估覆盖相同1836个训练窗口、40个开发窗口和三个初始噪声。8步预测必须逐元素精确重放193195保存的预测，否则作业失败。报告包含路径、第16目标、夹爪事件、逐任务与逐演示结果。若增加步数仍不能显著优于静止，epsilon单变量对照即可停止；若随步数恢复，再判断性能与计算成本是否可接受。

入口：[评估脚本](../code/evaluate_bridge_epsilon_steps.py)与[集群脚本](../scripts/cluster/bridge_epsilon_steps.sh)。
