# 全窗口冻结模型采样对照

目的：确认190952在40个训练诊断窗口上的发现是否也出现在完整训练集。复用190189的latest权重、归档模型代码、固定数据划分及现有环境，不训练，不读取保留测试目标。

本地真实读取通过：1836个训练窗口、40个开发窗口，来自405/10条演示。此次比较使用全部固定窗口，覆盖断言及保留测试排除测试通过；本地没有加载模型或下载权重。准备证据：[JSON](../reports/bridge_full_chain_local_preparation_v1.json)。

GPU对照使用三个采样种子（不是三个训练种子），比较：

- 纯初始噪声上的第一次x0预测，复用原随机链路t=99的预测。
- 原生产100步随机采样。
- 保持相同初始噪声、临时将posterior_variance置零的100步链路；结束恢复缓冲区。

生产model.sample和权重不修改。两条链路的初始状态及第一次预测必须逐元素相同；参数哈希前后相同且没有梯度。报告包含总体、任务和七个中间步骤的位姿误差。无步间噪声组不是DDIM，结果不能直接作为机器人成功或采样公式错误的证明。

由于窗口数量、排序和批次改变，此次种子映射与旧80窗口报告不作直接重放对比；本次三个条件内部保持配对。重叠窗口不视为独立样本。

脚本默认申请一张此前已实际运行成功的L40，40分钟上限不代表运行时间保证。复用集群缓存，包只含脚本和准备记录，不包含数据、权重或环境。GPU结果尚未产生。
