# 64窗口拟合复核：201429独立核验

结论：初始化42重复了初始化43的64窗口训练拟合成功。原32和新增32窗口均32/32达标，后期四次观测两组及整体门槛均通过。两个初始化仍均未通过同任务留出评估。

## 文件与配方核验

所需13份小文件齐全，共4,485,167字节（约4.28MiB），无PT。检查了源文件/清单/入口快照、104输入、共享初始化、Adam状态衔接、4096条逐步更新的学习率/有限loss/模块梯度及全部8份预测。报告执行检查通过，CLIP及其他冻结参数未变，夹爪未训练。

与200600对照，64训练/40开发窗口身份、模型配置、抽样顺序、更新预算、学习率与采样设置一致；所有104处理后输入哈希以及保存的训练/开发标签完全一致。训练入口只把初始化43改为42，反向替换后与200600快照全文相同。模型、dataset和其他源文件哈希不变。

CPU float64独立复算路径/终点位姿误差、静止误差、每演示误差以及原/新增子组门槛。最大位置复算差异约0.0000024cm，旋转约0.0042°，不影响门槛结论。只是重新计算保存预测，没有训练或运行模型。

## 证据范围和下一步

64窗口训练拟合在两个初始化下可以复现，支持固定数据处理、Adapter和多尺度扩散位姿头这条通路具备联合学习能力。新增演示能够学好，原演示仍能保留拟合，削弱“模型完全不能学”及“只能记住原32窗口”的解释。未证明所有数据处理语义都正确、全部1836窗口可拟合、新任务泛化或机器人操作成功。夹爪冻结，未运行仿真；泛化根因仍未定位。

64窗口复核这一项可收口。下一阶段保留这64窗口，再扩展到128窗口，保持相同配方和每窗曝光，观察原/新增训练误差与优化轨迹，检验扩大规模后是否仍能拟合。[128窗口包](BRIDGE_GROWTH128_FIT_20261013.md)已冻结，本地预检及独立复核通过，正式集群训练尚未提交。本阶段只说明训练拟合，不能用持续小规模记忆代替泛化评估。
