# 首时间步审查与对照草案

2026-10-18。207558仍为主参照，209481关闭。本文是审查结果和设计草案，不是可提交的训练协议。

## 已核实

仅读取既有405训练、10已用开发演示，逐条匹配原载荷SHA；未解码图片、加载模型、修改数据、训练或读取最终25条内容。

405/405训练与10/10开发的原始首步前六维运动指令范数均小于1e-5，最大值分别为1.252e-6与8.253e-7。这些是原始数值单位，不含夹爪维，也不意味着第一步实测姿态完全静止：下一次观测位移小于0.5cm的分别为374/405和9/10。没有时间戳证据可以确定控制时延。

[OpenVLA的Bridge变换](https://github.com/openvla/openvla/blob/main/prismatic/vla/datasets/rlds/oxe/transforms.py)移除第一时间步，项目保留起点，这是处理差异；不是Diffusion Policy成功PushT检查点在同一数据上的对照。当前监督来自实测到达位姿，不能因原始指令接近零就认定目标标签错误。

## 单变量对照必须固定什么

唯一研究问题：减少训练中的记录初始化输入，是否改善同一批新演示的近端预测，同时保留原完整16目标优势？不能通过删评估起点使分数下降。

1. 候选只变404个输入起点；图片、当前状态、未来目标整体从同一新起点重建。沿用原到达位姿、坐标、四元数、夹爪与图像规则，不能只移动图片或标签。
2. 1431个非起点窗口及一条短演示例外逐项保持。1836行、405演示、任务槽位、抽样索引表一致；模型、优化器、更新数、学习率、冻结范围、采样器不得同时改动。
3. 所有方法仍在209481已使用的10演示50个原窗口上评价，保留全部10个start0，不预热跳帧，不按真实位移门控；这些数据已是开发集，不能改名为最终测试。
4. 第一目标位置/旋转用于诊断；完整16目标、终点、起点/后续、逐演示结果全部报告。不得用一个较好分组代替原总体，或用远期优势掩盖近端仍差于不动。
5. 原207558保存预测直接作固定参照，不为重得相同分数重复正式训练。只有起始状态、配方、随机计划可证明匹配，才能解释为取窗对照；若从207558继续微调，则需要等预算控制，不能混称从头训练。

训练起始方式、预算和正式采用门槛尚未选定，GPU入口未实现，草案不能提交。

## 当前决定

完成本轮审查，**不因首步原指令近零就安排训练**。该现象尚不能区分合理的初始化样本和错误监督。已有结果中，去掉起点的开发第一目标位置仍为模型1.638cm、不动1.568cm，说明首步不能解释全部近端泛化问题。

若采用此方向，先明确初始化输入是否属于部署任务，再形成起始方式、预算、验收完整的协议。若没有排除该输入的任务依据，应终止删首步路线，不追加变体。评估起点始终保留，207558已有全段离线优势不因本轮审查失效。

证据：[数值和源身份](../reports/bridge_initial_step_contract_20261018/report.json)、[逐任务数量](../reports/bridge_initial_step_contract_20261018/inventory.csv)、[审查候选索引](../reports/bridge_initial_step_contract_20261018/review_only_candidate_rows.json)、[脚本](../scripts/audit_bridge_initial_step_contract_20261018.py)、[起点/后续误差](BRIDGE_LOW_MOTION_TIMELINE_20261018.md)。

## 部署语义核对后的决定：关闭删首步候选

继续检查当前固定源，而非运行新模型：

- `reports/bridge-coverage-rep-fit-207558/runner_snapshot.py`的`context(indices)`只组合当前视觉/语言Adapter、重复当前输入的历史端口与9维当前位姿投影；没有输入记录索引、`is_first`或真实原始动作指令。
- `cluster_packages/bridge_prefix_pair_v1/frozen/state_input_contract.py`的`state_features`为当前XYZ标准化加6维旋转列。不是记录时间、速度或启动标志。
- `scripts/bridge_prefix_input_contract_v1.py`读取`steps/is_first`用于数据身份/结构检查，不将其作为模型条件。不能把加载器知道是首帧，等同于策略接收了启动信号。图片/姿态可能间接包含相关线索，不能因此断言模型绝对无法辨认。
- 当前参照仍是Bridge离线策略，尚无该权重已验证的Bridge机器人闭环启动映射。旧Panda实验使用其他数据和权重，不能用其`reset`语义证明207558遇不到类似低运动状态。

结论：现有任务定义没有依据排除记录初始化状态，且已有监督是实测未来位姿，并非把接近零的原始运动指令直接当运动标签。**“首步原指令近零”不是足够的错误证据。关闭本次删首步训练候选，不准备作业，不移动训练或评估窗口，也不新增启动标志/静止阈值变体。** 原审查候选文件仅留作证据，不成为活动配置。

这关闭的是一条缺乏任务依据的干预路线，不是否定已经定位的近端低运动误差，也不宣称近端泛化已解决。207558完整16目标的既有离线优势保持；下一次训练提案必须直接针对可验证的实际决策问题，而不能仅以公开管道某处不同为依据。
