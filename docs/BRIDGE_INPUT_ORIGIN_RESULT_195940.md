## 判读

中低噪声时间步的误差差距遍布全部任务和演示。它提高了反向采样输入偏移/误差累积的排查优先级，但无法单独确认根因：真实动作加噪输入含有真实未来信息，两类输入不等价，统计差距也可能受模型条件能力和多模态动作影响。

真实加噪输入 t0 位置仍有 1.329 cm、旋转 11.565° 误差，不能认定去噪器完整拟合，更不能由此宣布 CLIP/Adapter 正确。

位置裁剪：所选真实目标 xyz 超界比例为 0；六个记录时间步的两类 x0 预测 xyz 裁剪比例均为 0。因此这个子集中的位置上限不是优先解释。没有核对未记录时间步或四元数裁剪，不能作全局排除。

## 下一步决策

不重训，不再重复步数扫描或 EMA 调参。下一项应为真实张量的采样器实现对照：固定相同 x_t、去噪输出、时间步和每步高斯噪声，与作者使用的 DDPM scheduler 核对每步均值、方差、裁剪顺序及更新结果。已有 CPU 玩具公式审计未发现确定错误；这一步须补足真实模型路径的一致性，不能把公式错误预设为根因。

若更新一致，就降低采样实现错误的优先级，把重点转向条件信息、训练目标和动作表示；若不一致，定位首次差异时间步再修复。该对照尚未实现或提交。本次只完成现有报告分析。
