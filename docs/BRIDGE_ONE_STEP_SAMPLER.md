# Bridge同权重一步x0采样对照

准备日期：2026-10-08。该实验只加载192651已经训练完成的扩散权重，不训练、不更新参数，也不读取保留测试目标。它回答一个窄问题：当前扩散网络在最高噪声`t=99`处直接输出的`x0`，是否比继续执行完整100步DDPM反向链更接近目标。

## 配对设计

- 数据仍为固定1836个训练窗口和40个开发窗口，完整轨迹划分、顺序与192651一致。
- 模型为`/projects/Zeroshot/runs/bridge-head-train-192651/diffusion-final.pt`。
- 三个种子仍为0、1、2；每批使用`seed*10000+start`，使一步输入噪声与192651完整采样的初始噪声对应。
- 一步分支将纯高斯噪声送入`t=99`的x0预测U-Net一次，再使用生产代码相同的位置裁剪、四元数单位化及夹爪状态头解码。
- 对照直接读取192651保存的回归与完整100步扩散预测，不重新生成它们。
- 同时报告16目标平均误差、第16目标误差、真值夹爪事件位姿和时刻、逐任务与逐演示结果以及仅诊断用oracle best-of-3。

若一步结果已经很差，主要瓶颈在高噪声条件下的去噪/条件建模；若一步明显优于完整链，则反向链的分布漂移或误差累积是重要瓶颈。即使一步更好，它仍是对DDPM训练模型的推理消融，并非经过一步生成训练的一致性模型，也不能代替仿真成功率。

入口：[评估脚本](../code/evaluate_bridge_one_step_sampler.py)与[集群脚本](../scripts/cluster/bridge_one_step_sampler.sh)。

## 193030结果

作业COMPLETED、退出码0:0，用时1分47秒；实际评估段50.71秒，峰值显存1.86GiB。来源训练报告和窗口参考哈希与本地证据一致，覆盖1836个训练窗口与40个开发窗口；没有训练、权重更新或读取保留测试目标。

开发集三个种子平均：一步x0为7.672cm/14.726°，第16目标10.156cm/19.424°；保存的100步随机DDPM为10.235cm/16.472°，第16目标13.687cm/20.925°；回归为6.626cm/12.108°，第16目标8.324cm/14.660°；静止为8.212cm/15.098°，第16目标10.565cm/19.986°。一步相对完整链稳定改善，但仍弱于回归。

10条开发演示中，一步的路径位置9条优于完整DDPM、8条优于静止、仅2条优于回归；第16目标分别为8、7、2条。夹爪抓取切换为各种子4至5/20，释放仍0/8。结果把100步误差累积确定为重要瓶颈，但也证明高噪声一步预测与夹爪头仍不足。下一项是固定权重的[确定性DDIM步数对照](BRIDGE_DDIM_STEP_SWEEP.md)。原始证据：[完整报告](../reports/bridge-one-step-193030.json)与[核对摘要](../reports/bridge_one_step_193030_verified_summary.json)。
