## CPU检查实际验证了什么

使用合成224×224校准图、固定已有指令及当前状态，完成真实CLIP编码和完整上下文计算。接口从图像直接计算、从同一CLIP token计算，以及207558 runner原上下文表达式，三者逐元素相同。当前状态统计仍是原128个训练观察的固定统计；没有未来状态输入。

完整模型中原可训练参数132309639，新请求投影16384，总计132326023。接口仅持有一份U-Net；新条件通过弱引用调用原头，避免重复注册/重复检查点键。创建新条件不改变原随机数状态。

完整16步损失在同随机时间步/噪声下与存档模型的diffusion_loss预测和MSE逐元素相同。一次完整规模K1/DDPM100生成返回1×1×7有限位姿，四元数单位化。训练态一次反向计算中Adapter、U-Net、历史、当前状态及请求投影均有有限非零梯度；CLIP和夹爪无梯度。没有optimizer.step，全部参数指纹未变。

新训练权重格式分开保存原可训练参数和新增请求投影，不猜测旧文件格式。已在内存检查约529MiB可训练张量的保存/加载接口及未知键拒绝，没有写新PT文件；这不代替后续集群磁盘检查点/Adam恢复验证。CPU完整检查约9.66秒，不含解释器导入。

## 唯一一项对照设计

从**同一训练好的207558检查点**开始两组，各最多4096次新增更新。原207558不覆盖、不重新训练来当对照。

| 项目 | 新接口控制组 | 后段覆盖候选组 |
|---|---|---|
| 原始起点/任务 | 同405条演示、五任务 | 相同 |
| K16分支 | 旧1836个完整起点 | 完全相同的起点及batch |
| K1分支 | 旧1836个起点 | 3394个起点，包含1558个后段观察 |
| 新增请求条件与其初始化 | 相同，零初始化 | 相同 |

| 优化 | fresh Adam，固定1e-5，无weight decay，梯度裁剪1 | 相同 |
| CLIP/夹爪/状态统计/图像处理 | 保持原冻结规则，无增强 | 相同 |
| 随机性 | 同更新的dropout与扩散随机种子 | 相同 |
| 检查点 | 仅最终第4096次，非早停/选最好轮次 | 相同 |

旧final_trainable.pt没有Adam状态，因此两组明确使用相同fresh Adam，不能称接续旧优化器轨迹。新增更新总数8192是两组合计；每组此前已经继承207558的8192次训练成果。4096是一次有界继续训练的预定预算，不保证足够收敛，也不因结果不好而自动延长。

匹配抽样数组已生成，尚未用于训练。候选K1中3394起点都获得3至8次抽取，共7627次抽到新增后段起点。K16 batch逐元素相同，两个分支的任务槽逐元素相同。扩大K1池也降低了旧起点在该分支的重复曝光，因此比较的是固定算力下的实际覆盖方案，不能唯一归因纯粹的演示阶段内容。

两组都使用新接口，组间只改变K1输入池；这能将“新增请求条件/目标”和“后段覆盖”分开。与原207558的比较另行报告，它不是架构不变或总累计算力相等的比较。训练仍只研究位姿，不夹带新夹爪损失、数据源、任务、真实历史或旋转权重。

## 开发与最终验收

本轮只读已有元数据，不读取图像/状态/动作。新开发候选按事前固定身份哈希选出每任务2条共10条，元数据预计50个完整16步窗口。它们位于分片256之后，排除了既有810条训练候选清单（含后续剔除者）、旧开发、已消耗13验收及原预留25最终候选，并核对来源文件加episode_id身份不相交。

这只能说明没有出现在已核对的这些清单中，不是对所有未记录历史使用的绝对保证；相机/布局独立也未经证明。新开发的数值/图像资格尚待检查，若不符合既定schema则在训练前停止，不按模型表现替换。**当前是元数据候选，不是已经可用的50个真实测试窗口。**

最终25条直接沿用10月17日已预留的每任务5条身份，不重新挑选、不读目标。只有最终权重/配方冻结且新开发门槛通过，才一次评价候选、配对控制、原207558及静止基线；这是同任务独立演示离线验收，不是LIBERO/CLIPort或零样本抓取benchmark。

主指标仍是**完整16步路径位姿误差**，演示等权，并同时报告窗口等权、所有任务/演示、终点及第1目标。固定最终检查点在新开发集上的采用条件为：

1. 候选的演示等权路径位置严格低于配对控制、207558和静止。
2. 候选的演示等权路径旋转不高于上述三者。
3. 至少同6/10条演示的路径位置同时低于配对控制和207558。
4. 窗口等权路径位置/旋转均不高于配对控制和207558。

K1是单独的辅助结果，不能用更短预测的低误差替代原16步指标来宣布进步。不使用旧40开发或已看过13验收来选模，不根据开发结果挑中间轮次、学习率或种子。上述是一次工程采用规则，不是统计显著性证明，也不保证物理成功。
