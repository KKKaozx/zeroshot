# 官方采样更新和现有条件证据核对

## 196610

40 条训练演示的真实生成张量，全部 100 个时间步，与 diffusers 0.11.1 DDPMScheduler.step 在容差内一致；最大 xyz 更新差异 0.0000369549 cm。独立 cosine beta 和共享累计 alpha 表差异为 0。t99 的 x0→epsilon→x0 最大浮点差异约 0.0002418，但实际更新最大差异仅 0.000003755，因此不能将这个中间浮点差异当成厘米级失败解释。

只验证逐步条件更新，不是完整官方自由运行策略，也不验证梯度、拟合、条件编码或泛化。

## 当前多尺度 193761 的图像交换

使用 194978 已完成的 40 训练窗口、3 采样种子、纯噪声 t99 一步估计。正确图像的位置误差 8.355 cm、旋转 14.405°；同任务交换图像后 8.425 cm、15.650°。预测本身的位置平均改变 1.196 cm。

图像确实影响模型输出，不能说视觉链路完全未连接或完全忽略图像。交换图像后的误差仅小幅增加，不能证明模型已学会准确的物体/末端定位，也不能仅凭该差异认定 CLIP 或 Adapter 故障。

旧紧凑模型 190853 的跨任务语言交换引起预测位置变化；191256 完整窗口图像交换增加误差。这些是不同 checkpoint 的证据，不能拿来确认当前多尺度模型的语言理解或视觉定位正确。没有重复启动这些检查。

## 当前排查状态

- 降低已测路径上的 DDPM 更新公式实现错误、EMA 缺失、所测窗口位置裁剪超界的优先级。
- 保留当前生成学习未充分拟合的可能：完整训练集生成误差也较大，真实加噪输入的还原不能替代纯噪声生成检验。
- 保留条件信息不足/利用不足的可能，但尚不能定位 CLIP、Adapter 或 U-Net 中的单个模块。

若继续，应先选同一多尺度模型的小样本纯噪声生成正对照，保持动作表示、损失和采样规则，明确检查完整生成链的基本拟合能力。此前旧模型/旧数据上的记忆结果不能替代当前配方的对照。成功仅证明该小样本可拟合；失败也不能自动判定某模块有代码错误。具体预算和通过标准需在实施前固定。此处只整理决策，未创建或提交新训练作业。
