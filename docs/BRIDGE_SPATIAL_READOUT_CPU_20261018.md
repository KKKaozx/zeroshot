# 区域加权读出CPU接口验证

2026-10-18。承接[结构审查](BRIDGE_ADAPTER_READOUT_REVIEW_20261018.md)，只实现隔离读出原型，未接入生产Adapter、训练runner或提交入口。CLIP保持冻结且本轮未加载；207558权重、固定源码、数据和评价不变。

## 实现与范围

新增1026个评分参数：1024维内容评分和2维固定图像网格坐标系数，初始化全零。对融合后的patch算softmax权重，再与CLS各取一半，沿用原output_norm。代码用`原patch均值 + sum((注意权重-均匀权重)*patch)`的等价残差式，在零分数时保持原均值求和路径，同时保留新增参数梯度；没有根据零权重分支跳过计算或截断梯度。

验证输入为合成float32 `[2,257,1024]`。导入存档Adapter代码，只实例化零个交叉注意力块以执行其**真实末端读出代码**，并复制同一非默认LayerNorm作为比较；合成输入代表八层之后的token。没有执行真实八层Adapter、CLIP、扩散模型或旧207558检查点，不构成实际策略重放。

没有创建优化器、执行参数更新、读取任何训练/开发/最终数据。激活权重的测试使用单独手工指定参数副本，不是训练出来的候选。
