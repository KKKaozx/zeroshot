# 当前末端状态配对：202278核验结果

本轮发现小幅、值得复核的条件输入收益，但未解决开发泛化问题。两组128个训练窗口全部达到既定拟合门槛；真实状态组的开发路径位置和旋转平均误差均下降，10条开发演示中7条位置改善，满足原计划的候选筛选条件。整体仍略差于静止基线，不能宣布泛化通过或确认唯一根因。

- 202277预检和202278正式配对均COMPLETED/0:0，在A6000执行。正式27份必要小文件、16份预测快照齐全；每组8192条更新日志及学习率切换核验通过。
- 输入身份、状态同索引、仅训练统计量、冻结源码、共享初始化和不使用未来状态的约束核验通过。真实接口有非零梯度及权重/上下文变化；零接口保持零，冻结参数不变。
- 保存的零组最终训练和开发预测与201663原控制逐元素完全一致，最大差异均为0。这排除了本次控制计算意外改变这一解释。
- CPU从保存预测独立复算指标与门槛。浮点精度及四元数转角计算使旋转末位略有差异；最大位置指标差1.82e-6 cm、最大旋转指标差0.0174°，均在既定验收容差内，不改变任何结果分支。
- 本地未下载PT、未重训、未加载模型；两份集群权重元数据合计1,058,750,340字节。权重文件内容没有本地复核。保留测试演示未用于本轮评价。

证据支持“显式当前状态在这次初始化下帮助部分开发演示”。不证明它是主要或唯一根因，不证明全1836训练窗都已拟合，不证明未见任务零样本能力，不证明PyBullet闭环抓取成功。

## 下一步与停止条件

按[先前固定计划](BRIDGE_DIAGNOSTIC_PLAN_20261013.md)，只允许再做一个预先固定的不同训练初始化的完整零/真实状态配对，保持数据、接口、预算和评价规则不变。初始化42复核202463现已完成并独立核验：位置/旋转整体小幅改善，6/10演示位置改善；候选条件重复，但仍未通过静止基线，且真实组只有117/128训练窗达标。该配对本轮收口，不再追加种子。见[复核结果与下一阶段](BRIDGE_STATE_REPLICATION_RESULT_202463_20261014.md)。

两组须先达到训练拟合门槛，再判断是否重复“整体路径位置/旋转均改善且至少6/10演示位置改善”。若不重复，记录为不稳定收益并停止这个方案，不继续挑种子或扫接口层数/权重。即使重复成立，只要仍差于静止，也只能确认部分收益，不能直接进入成功的泛化或抓取结论。
