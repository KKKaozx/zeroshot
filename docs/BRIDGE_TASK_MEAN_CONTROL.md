# 仅训练集任务平均动作对照

真实读取190189固定数据包中的1836个训练窗口、40个开发窗口，清单及归档模块哈希与191004完全一致。每个任务分别用训练窗口计算16个相对未来时刻的xyz均值与四元数Markley均值；未输入图像、当前状态或开发目标。开发数据仅用于评分。训练分数是拟合均值后在原训练集的描述性结果，不是交叉验证。

复用归档物理误差函数，逐组复核静止误差与191004一致。相反符号四元数不抵消、逐时刻均值保留两项测试通过。没有加载模型、下载权重、训练神经网络或读取保留测试目标。新增报告约20KB，数据未复制。见[计算脚本](../code/evaluate_bridge_task_mean.py)与[结果](../reports/bridge_task_mean_control_v1.json)。

第一次预测比任务均值的总体开发位置好0.273cm（约3.5%），旋转差0.177°。训练位置好0.290cm、旋转差0.020°。不看图像的均值本身已优于静止，因此超过静止并不能单独证明模型利用了视觉阶段信息。

逐开发任务：模型/任务均值位置分别为微波炉9.492/8.929cm、关抽屉8.047/8.296、开抽屉6.436/6.947、西兰花8.265/8.961、拨杆2.392/3.186。四项模型位置较好，但改善幅度有限；微波炉较差。旋转只有开抽屉较好，其余四任务比各任务均值略差。不能以总体相近认定逐样本输出相同、完全忽略图像或统计上无效，尚未计算演示层面置信区间。

下一步收敛到一次预测的视觉条件对照：同任务不同演示换图，保留语言与初始噪声，以正确图像/换图相对于任务均值的误差差异检验信息利用。已有190853换图结果针对完整100步，不能替代该一次预测对照。先不重训、不增加数据或改采样器。均值旋转不是角度绝对误差的最优估计，不能将该对照视为性能上限。
