# 工具轴与基座轴位置表示：CPU审计完成，不启动训练

本次按事前范围完成当前806训练演示/3624窗、原10开发演示/40窗的XYZ表示审计。没有加载项目模型、编码图像、拟合神经网络、使用GPU或提交集群作业；原模型和标签保持不变。主执行约8.36秒，仅复用项目已有数据，不读取E盘或预留测试。

## 具体比较及数据复用

工具轴标签`d_tool`是从固定当前位姿到未来16个到达位姿的相对位移。新候选只用**输入时刻**朝向构造`d_base=R_current @ d_tool`；起点、目标时刻、单位、四元数标签均不变，不累计逐步增量。

训练标签分别在两种表示下按任务取一次算术均值。开发时基座轴先验用合法当前朝向映回原工具轴`R_current.T @ prior_base`，再使用原XYZ欧氏距离；没有用开发未来姿态作为条件。需要注意，基座轴先验在映回时利用了当前朝向，两个简单先验不是完全相同的输入映射，这不是对神经网络坐标表示效果的因果检验。

当前姿态复用原168输入及新增1788输入缓存，共1956行。只对缺失的1708条旧训练行，从已有导出数据的392条演示/204分片按原record_index和start_index读取当前state。分片字节SHA匹配旧导出清单，空占位保留原编号；跳过图像字段，不解码图片。读取了约799MB已有分片以校验字节来源，但没有重做旧几何/图文编码实验，也没有扫描原始E盘。

## 新变换核验

这不是重做原始标签构造审计，而是验证新加入的坐标变换：float64旋转正交性最大误差4.44e-16，行列式误差5.55e-16，工具→基座→工具最大差1.42e-14cm，两个坐标系中距离最大差7.11e-15cm。原工具轴先验与上一轮保存预测逐元素相同。

另用SciPy从RPY转四元数的独立实现及one-hot分组求和重建基座先验，训练均值/预测最大差均5.77e-15cm；窗口和演示计权重新核对通过。该核验直接复用本次保存姿态，没有再次提取204个分片。1956行原姿态缓存复用值全部精确匹配。

## 收尾和解释边界

这项有限的CPU先验审计没有支持换坐标表示作为下一项GPU训练，候选分支关闭，不创建新预检、不改标签、不把旧8192权重的输出重新解释为基座轴。

它不证明所有神经网络在两种表示下都表现相同，也不把工具轴表述为已确定的泛化根因或数学错误。此前上下文读出超出任务平均先验的证据仍有效，但唯一瓶颈尚未确定，没有新的扩散性能提升。

开发集已多次使用，没有新独立测试结论；本轮仅XYZ，不含旋转预测、夹爪、物体定位或抓取成功。
