- 100步位置误差高于同模型一步预测：原尺度383/405训练演示、9/10开发演示；归一化370/405训练演示、8/10开发演示。按每演示的三次采样平均比较。
- 100步位置误差高于静止基线：原尺度284/405训练、6/10开发；归一化267/405训练、7/10开发。不是每条演示都失败。
- 归一化相对原尺度：开发6/10演示路径位置变差、7/10窗口终点位置变差；训练位置222/405演示改善，但252/405旋转变差。

降低“本次位置归一化配方能修复生成失败”的优先级。DDPM单步更新已与官方库对齐；EMA/本次归一化都未解决整体问题。训练集完整生成误差也高，故不能仅归因泛化。尚未判定CLIP/Adapter/U-Net中的单个模块错误，也未全面证明真实数据时间语义正确。

下一项应是当前原尺度多尺度x0配方的单窗口纯噪声完整生成拟合正对照：固定一个原训练窗口及其图像/文本/标签，不改模型、动作表示、DDPM公式和损失；预先固定更新预算与精度门槛，同时报告一步与100步、真实物理位姿与夹爪，不能仅用去噪训练loss判定通过。旧紧凑模型的记忆结果不能代替此配方。
