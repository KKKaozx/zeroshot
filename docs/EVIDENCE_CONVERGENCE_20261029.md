# 接手后的证据收敛与下一步决策（2026-10-29）

本文基于完整接手指南及已保存证据，完成指南第7节的第一项：区分配方差异、已检验解释和剩余阻塞。本文不是新实验协议，不授权训练、重新评分、远端操作或发送邮件。没有重算已完成的233818结果。

## 当前结论

当前优先问题是四源配方的多窗完整动作生成能力，不能仅称目标域泛化差。233818在固定起点和4096新增更新下，32个训练锚点及88个开发窗的各14项可用来源均值，全部差于旧控制与不动。训练锚点在固定计划内新增46–76次曝光，结果不支持“只要缩池增加重复就能解决”的处理。

另有独立的执行阻塞：当前5Hz未来实测到达位姿与LIBERO原生20Hz控制器设定点不等价。已排除工程任务中原生动作和20Hz专家位姿成功，5Hz表示及其特定插值控制失败。源内生成改善也不能自动解除这一阻塞。

正证据继续保留：旧Bridge离线优于不动；同旧配方换DINO仍能改善；Push-T支持DINO骨干选择；当前固定8窗能显著学习。这些证据的任务、数据和评价口径不同，不能拼接成OXE→LIBERO成功率。
