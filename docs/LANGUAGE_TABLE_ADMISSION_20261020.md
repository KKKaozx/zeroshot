## 老师原意

核对本地《第三封邮件》《第四封邮件》：老师指出 Language Table 使用推杆而非标准夹爪，要求记录动作空间差异、讨论对跨注意力对齐的影响；推荐四来源主训练时明确使用真实机器人 `language_table`，不混入仿真或 oracle 数据。邮件没有要求将推杆伪装为已张开的夹爪，也没有提供真实工具朝向标定。

[作者数据说明](https://github.com/google-research/language-table#datasets)将真实 `language_table` 与仿真数据分开。[原论文第V节](https://arxiv.org/pdf/2210.06407)说明动作是相邻控制设定点之间的二维增量，并将采集训练与推理数据整理为5Hz。**控制设定点不等于实际到达位置**；当前统一读取器使用未来实际位置作为监督，不能把原生 action 直接当成同一标签替换。5Hz来自论文，不是每条本地记录独立验证的时间戳。

## 完成的夹爪处理

仅修改 `code/dataset.py` 的 `_get_tfrecord_language_table_xy`：新命令输入模式返回 `[0,0]`，表示没有可用夹爪命令；旧模式继续返回原来的一维占位，旧图像、动作及监督mask不变。新模式的构造器仍会拒绝实际纳入 Language Table，因为坐标接入未完成；直接解析器检查不等于绕过构造器的正式训练。

复用实际主 `policy_loss` 与评价函数，补查本次缺失监督的梯度与计数，没有重跑拟合：

- 只对源XY两维计算直接损失；sample与epsilon输出测试均通过，其他位姿输出梯度为零。
- 无夹爪标签时，夹爪输出没有梯度，独立夹爪参数也不会被该次AdamW更新。
- 混合批次中，夹爪BCE仅来自具有真实夹爪目标的样本，推杆样本不增加夹爪分母。
- 评价中缺失旋转和夹爪结果为NaN，不生成虚假的准确率或开合事件。
- 固定模型输出时修改无效目标不会改变损失。这**不证明**耦合降噪网络的有效预测不受输入占位值影响；没有加载实际降噪模型。

证据：[部分监督检查](../reports/language_table_overlap_20261020/partial_supervision_check.json)。仅3个合成窗口和直接输出张量，非真实模型训练、非泛化成绩。主损失源码没有修改。

## 现有真实缓存的共享帧分组

遍历已有8个train分片的全部3,436条候选，通过TensorFlow TFRecord读取器检查记录CRC，并核对原候选偏移、长度、记录数、字段尺寸/有限性、首末标记和UTF-8指令。没有下载、复制原始数据或解码图片。全部记录通过本次结构检查。

55,155个帧出现中有54,742个不同的编码图像SHA；413种图像在多条记录中出现。按任一相同编码图像连接记录、再取传递闭包：

| 项目 | 数量 |
| --- | ---: |
| 候选记录 | 3,436 |
| 共享帧连通组（含单条记录） | 3,370 |
| 多记录组 | 64 |
| 多记录组中的演示 | 130 |
| 多记录且有不同语言标签的组 | 64 |
| 最大组记录数 | 3 |

这是实际发现的泄漏风险，**不是证明以前Bridge结果有泄漏**。这些Language Table记录尚未分区或训练。以后划分必须至少保证同一共享帧组不跨集合。

为后续预算枚举了完整16未来帧、步长4的候选：1,414条记录能提供3,760个完整窗口。这不是最终筛选规则；其余短记录仍留在清单，不因该统计就被丢弃。是否保留短轨迹的部分窗口和对应时间mask还需统一确定，不能靠重复末帧冒充新的真实监督。

[记录与组清单](../reports/language_table_overlap_20261020/episode_groups.json)保存逐帧SHA、记录身份、分组、候选窗口起点；[检查报告](../reports/language_table_overlap_20261020/report.json)记录来源指纹、CRC/结构结果及边界。分组算法已检查传递连接、重复帧和记录次序不变性，且真实清单中共享编码帧不跨组。

**边界：** exact JPEG匹配只能发现部分重复；不同编码的同一画面不会匹配，完全静止且字节相同的画面可能保守合并不同原始操作。当地schema没有原始采集session/演示ID。当前3,370组不等于已证明相互独立的3,370次物理采集，扩池时必须重新计算连接关系。未据此冻结最终验证划分。

## 尚未接通的坐标问题与下一项

四个本地观测字段没有末端朝向。现有统一动作把位移旋转到观测时刻的工具坐标系，而Language Table的原始二维坐标不能仅凭名称视作同一坐标。论文的二维约束、仿真固定朝向或其他项目补零/补open的约定，都不能替代真实坐标映射证据。

本次还比较了原生action与目标设定点差分的相邻行关系。相同行误差比前后移一行小，但并非逐元素相等，**不据此宣布精确时序已经对齐，也不移动标签以拟合结果**。原始数值在报告中，单位未转换为厘米。

下一项需落实一条明确路径：获得适用于真实数据的源坐标→工具坐标依据；若公开资产确实无法提供，则在新的四来源主训练协议中统一设计可观测的位移表示，而不能只给Language Table冒用单位朝向。该表示必须同时约束其他来源和LIBERO解码，旧207558合同保持冻结。当前仍不生成四来源正式训练提交命令。
