# LIBERO主线准备：实际窗口与训练指令目录

2026-10-25。本轮推进不依赖老师骨干选择意见的工作，全部在本地CPU完成。未训练模型、加载预训练骨干、运行物理仿真、提交集群作业或重跑Push-T。

## 已完成一：实际窗口接入

新增`code/oxe_window_index.py`，将已冻结的OXE整演示角色落实为实际Dataset可消费的窗口索引，并接入主`train.py --prepare-only`。旧模式默认不启用，新参数为`--oxe-window-manifest`。

输入是原来32个分片、约5.6GiB的四来源工程缓存，来源身份、payload、原始角色和已发现的共享内容组沿用10月20日结果。没有重新划分、抽取新来源、增加LIBERO示教或按模型误差选择窗口。索引以相对源路径、payload SHA、解析器SHA和真实行号建立身份；实际取样时三维来源也逐记录核对payload，分组采用全局内容/原始身份组，覆盖已知BC-Z重复记录。

采用现有默认：16个未来目标、起点步长4、整演示最少10行。尾部有效目标可少于16，存储补齐步监督为0。LT仅XY有监督，旋转/夹爪等缺失维度保持屏蔽。940条记录因长度或指令可用性不符合既有规则而排除，其冻结角色不移动：115条无指令Bridge、825条过短记录（其中另含3条无指令Bridge）。

实际主入口已产出`reports/oxe_window_index_20261025/main_prepare_seed42/split_manifest.json`。改为训练seed44时分区、身份和目标绑定完全一致。20项接线与拒绝检查通过，实际读取四来源各首/尾两个训练窗口共8个，目标有限且mask与协议一致；旧Dataset经过仅移除本轮新增路径可恢复到已记录的原SHA，原数值目标/四元数运算不改。没有重跑旧拟合、旧物理回放或旧合成恢复。

索引绑定`observed_future_reached_pose`，目标为t+1..t+16，三维来源配前一观测的首命令，原生BC-Z十槽诊断不混用。来源到米换算/时距仍显式未知，共同物理时间网格为null；旧0.1仅是目前数学除数声明，不是已证明单位。日志也明确显示单位和物理时间尚未验收。

**该格式仅允许prepare-only。** 直接训练或混用固定更新、旧权重/拟合入口，会在数据/模型初始化前拒绝。当前只完成实际窗口—Dataset—准备清单的绑定；完整训练checkpoint和执行器的真实物理合同仍未放行。

## 已完成二：训练专用指令目录

新目录覆盖35,933个训练窗口、3,363条训练记录，共**2,447条归一化后不同的原始指令**。按原冻结训练角色读取4.31GB训练payload并核对SHA，只使用语言字段，不解码图片、不构造动作目标；未读取验证/源留出记录或LIBERO/CLIPort任务指令。提取实际用时12.64秒。

每个窗口绑定原指令、行号、payload、分组、去重指令ID。空白折叠/casefold与现有LanguageAugmentor一致，原始文本同时保留，无UTF-8替代字符。生成了本地语言模型的输入清单：2,447条原指令，每条要求5条同义候选，共12,235个候选生成请求。

已完成固定本地Qwen模型和8条训练指令的两次短预检，第二次7/8组格式通过，但内容审阅只有2组凑齐5条文本可保留候选，尚不能扩展为正式训练标签。没有启动全量生成或构造反事实标签。目录格式与已审阅语言库隔离，现有增强器会拒绝将它直接用于训练，不能把候选清单算成四条件语言库已完成。见[本地语言生成预检](LOCAL_LANGUAGE_PILOT_20261025.md)。

另有至少**1,275个三维来源训练起始窗口**在当前图像前没有任何夹爪命令，因果命令输入应为[0,0]未知。反事实“不动”标签不能在这些窗口伪造打开/关闭状态；其他窗口也可能因未发生有效相对命令或中间值而未知。如何处理未知保持命令与真实场景不匹配证据，仍须在反事实训练协议中解决，本轮没有偷偷改动现有增强算法。

## 保留的正式前置缺口

1. 四来源单位、真实导出时距、轴/TCP映射及全部候选数值目标资格；8窗口读取不能替代整个池验收。
2. 固定本地语言模型，生成并审阅五条同义改写；反事实须有训练场景与目标不匹配及保持命令依据，不能仅凭不同文字造负标签。
3. 统一结构/来源采样权重/共同更新预算；当前原始窗口计数不均匀，尚未选择重加权方案。
4. checkpoint至LIBERO 20Hz执行的真实合同与正式任务/初始状态计划；已有工程成功不等于学习策略成功。
5. 第七封邮件已经确认冻结DINOv2 ViT-L/14为主方案、CLIP完整增强为单种子消融，共13次训练；骨干选择不再是等待项。主模型与策略回调的DINO接入已检查，见[新增接入](MAIN_DINO_INTEGRATION_20261025.md)。上述数据与执行缺口仍未关闭，不能据工程准备提交正式训练。
