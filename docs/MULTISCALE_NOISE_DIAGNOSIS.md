# 多尺度模型的固定权重根因诊断

194912完整评价已经取回。训练位置：回归3.984cm、紧凑单步7.701cm、多尺度单步7.597cm；开发位置分别6.626、7.672、7.363cm。多尺度在10条开发演示的位置上均优于紧凑单步，但只有2条优于回归。训练旋转13.819°还略差于紧凑13.642°。扩大结构不足以解决训练窗口本身的预测不足，不能单纯归因泛化。

下一项不训练，固定193761最终权重。按既定源顺序，每任务选择8条训练演示各第一窗口，共40窗口。开发图像/动作目标与保留测试不读取。报告每任务及整体的三个噪声种子结果，含物理位置/旋转误差和原始xyz/四元数MSE。

1. 对真实目标加噪，使用t=0/24/49/74/99，查看还原能力随信号减少是否明显退化；另单列完全纯噪声t99。这些还原测试包含真实目标，不能当机器人预测或部署指标。
2. 在完全纯噪声t99下，固定语言、目标和初始噪声，将图像替换为同任务另一条训练演示。生产预处理后的图像必须不同。比较误差和预测位置变化，判断图像是否提供有效的场景信息。

判读：若低噪声好而高噪声差，优先检查高噪声训练与条件学习；若同任务换图几乎不改变误差，则优先检查场景信息利用。若换图导致退化，说明本模型使用了有益图像信息，但不证明定位准确。三种子一致性和逐任务结果需一起查看，不能只据总体均值宣布根因。

如果两项仍不能区分原因，才进行有限固定窗口记忆实验。夹爪真实位姿/预测位姿对照另行处理，本次不混入。当前不新增训练预算、不使用开发结果选择checkpoint。该探针不能唯一归因某层代码或证明完整扩散策略有效。

入口：[诊断程序](../code/diagnose_multiscale_noise.py)、[集群入口](../scripts/cluster/multiscale_noise_probe.sh)。评价证据：[194912报告](../reports/bridge-unet-eval-194912.json)。

t99带噪真实目标与纯噪声结果极接近，与alpha_bar=2.43e-7相符；这排除了两种输入之间明显的结果不一致，不能验证其他采样步骤。t0的旋转误差仍约11.595°，但报告未记录带噪输入本身误差，因此尚不能宣布网络破坏了已有姿态。下一项若检验旋转还原，应先增加同一输入的恒等映射基线；判断学习能力则需要有限样本、同输入同目标的纯噪声记忆对照，避免用低噪声重建替代生成验收。

## 194978输入基线结果及生成末段检查

194978完整报告已取回，绑定194940来源，原输出位置/旋转指标重放差均为0。t0输入位置0.401cm/旋转4.608°，网络输出1.330cm/11.595°；五任务均退化。t24以上还原明显优于带噪输入，说明网络有去噪能力但最低噪声重建存在退化。此结果仍来自真实目标加噪，不能直接证明自生成链末段退化或某个损失公式错误。
