# 两维夹爪命令输入已接入主训练链路

2026-10-20。新增显式`--oxe-command-input`模式，默认关闭。旧一维实测/历史输入、既有Bridge207558和Push-T214273提交包不改。此次仅合成数据的一次优化更新和接口检查，没有真实数据训练或新泛化成绩。

## 数据、模型、训练与部署

三个已定义3D来源的实际解析函数在新模式下返回`[上一开正命令, 可用性]`。Bridge、BC-Z、Fractal分别沿用[前一阶段明确的因果规则](OXE_SOURCE_SEMANTICS_RULES_20261020.md)，不拿当前传感器值替代，不借未来初始化；原图像、位姿/夹爪目标和监督mask保留。

模型新增的两列输入只进入轨迹条件夹爪头，不改变CLIP、Adapter或位姿扩散的输入结构。未知为`[0,0]`，打开为`[1,1]`，关闭为`[-1,1]`；非法组合直接拒绝。旧模式仍为原1列投影和参数形状，新模式为2列投影，没有把旧权重静默补成新权重。

主`build_config`、数据身份、checkpoint data_config和恢复检查均记录新模式；旧/新模式不允许互相恢复或走旧迁移/拟合分支。新模式必须显式使用`--gripper-target-mode state`、切换加权1，采用绝对开合目标；不能在先前命令未知时构造第一步切换标签。

还需显式选择对应源的既有目标策略：Bridge `reverse_scan_valid_steps_v2`、BC-Z `preceding_command_v2`、Fractal `relative_scan_v2`。不自动改变原默认值，也不因启用新输入而放松原目标合法性检查。

LIBERO回调支持新的编码和语义配置。初始先前命令未知可传`None`，转换为`[0,0]`；执行器发出第一个原生命令后，后续调用可以携带已知的已发送命令。已发送不表示物理夹爪已完成开合。一维命令模型仍要求明确命令，不能传未知，也不能只凭旧配置的binary字段认定其训练语义。

## 评价分母修正

有有效目标时，夹爪预测准确率仍统计全部目标，输入缺失不等于监督目标缺失。保持先前命令的基线、相对先前命令的change/hold统计，只计算先前命令已知且目标有效的部分。

新增`gripper_persistence_eligible_steps`和`gripper_persistence_coverage`报告可用数量与覆盖率。全部未知时，保持基线和change率为NaN，而不是默认打开后给出误导成绩。原一维模式的已有指标保留原计算值。这里的change/hold是命令标签比较，不是抓取成功或实际物理切换。

- 与修改前源码快照对照，默认数据输出、配置、模型参数键/形状、预测及所有原有指标一致。
- 主模型、主`policy_loss`和AdamW完成一次合成更新，Adapter、扩散及命令/可用性两列有梯度，冻结CLIP无梯度。
- 完整新权重保存/加载后，推理支持已知和未知命令；旧1列权重加载为新2列被拒绝，实际恢复判断与数据身份模式隔离通过。
- 明确构造12个夹爪目标，其中8个有已知先前命令：保持基线为6/8=75%、覆盖率8/12；预测准确率仍为12/12。全部未知时覆盖率0、保持基线NaN。
- 原生执行器的未知初始命令可传给回调，合成反馈控制后记录已发送命令；没有MuJoCo物理步或成功评分。
- 实际数据构造器拒绝Language Table进入新模式。其余解析器（含Fanuc）和主`policy_loss`源码AST未改变。

## 仍未完成

这项接入解决的是输入语义与缺失表达，不证明它会改善泛化。Language Table的实机朝向/平面投影依据尚未获得，不能仅凭夹爪缺失编码就接入；主训练也尚未使用其投影损失。

实际候选清单仍需目标合法性、原始演示/共享帧分组、源时间/坐标验收和固定划分。四来源完整训练预算、步数式恢复协议、主干身份和真实模型LIBERO执行仍待完成，没有生成可提交的四源正式作业。
