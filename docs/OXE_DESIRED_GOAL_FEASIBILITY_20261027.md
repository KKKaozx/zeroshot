# 四来源期望控制目标的可恢复性

本次结论：**原生20Hz工程目标经过8维转换可执行，不等于四个OXE来源已经能够生成同义的新监督。现在不应整批替换标签或重训。** 下表将“字段存在”“数值可构造”与“物理和时序可执行”分开，保留现有两份训练终点。

本次只复核四个精确缓存版本的features元数据，复用已有BC-Z原生目标检查，并新增3条固定Language Table训练记录的目标/动作对应检查。没有使用验证或测试标签，没有图像解码、模型、仿真或训练；未生成训练目标文件。

## 新证据一 Bridge依赖的目标参考

公开采集器`RobotBaseEnv._next_qpos`读取上一目标变换，在当前末端位置周围构造动作变换，再与上一目标相乘，随后可能限制XYZ范围；`step`还可依配置重置上一目标。原始观测另外保存`desired_state`，而当前缓存schema仅有state等字段。该源码说明恢复目标可能需要额外历史量，不证明所有缓存演示都采用相同分支。[作者采集环境](https://github.com/rail-berkeley/bridge_data_robot/blob/main/widowx_envs/widowx_envs/base/robot_base_env.py)

旋转和平移的动作变换围绕当前EEF构造；不能忽略上一目标与实际EEF之间的差异。[作者变换实现](https://github.com/rail-berkeley/bridge_data_robot/blob/main/widowx_envs/widowx_envs/utils/transformation_utils.py)

这些是2026-10-27读到的公开分支代码，不是已恢复的历史导出提交。既有Bridge转换家族分析仍可复用，但不能将源码家族相符提升为精确版本恢复。

## 新证据二 Language Table真实记录的行对应

在当前冻结训练演示顺序中，事先选择第一、中间、最后三条Language Table记录；它们不是按误差或动作值挑选的。分别12、12、42步，原payload SHA逐项核对，合计读取3,756,778字节、约7.7秒；比较各自共同内部动作行，共60行，排除终止动作。

令T为记录的effector_target_translation，a为记录的action：

| 原始演示身份 | `T[t+1]-T[t]-a[t]`最大分量绝对残差 | `T[t]-T[t-1]-a[t]`最大分量绝对残差 |
|---|---:|---:|
| shard00626 record1 |0.019798|0.047767|
| shard00045 record0 |0.011112|0.020841|
| shard00630 record483 |0.033376|0.105673|

数值保留原记录单位，不写成米或厘米。三个样本两种关系均未落入1e-6数值检查界，不能将误差更小的关系直接选为正确行对齐。这里只否定两种具体等式，不证明整个数据损坏，也不证明当前到达位姿监督本身错误。

作者将动作定义为前后期望位置间的二维增量，同时说明实机100Hz状态、30HzRGB经异步配对组成名义5Hz训练对，并处理约80ms相机延迟。因此，相邻导出行的目标字段是否正好对应本行动作，仍需要精确导出/配对定义；不能凭这些残差猜一个延迟并整体平移标签。[作者论文第五节与附录A](https://arxiv.org/html/2210.06407v1)

## 复用证据 BC-Z不重复做旧检查

`reports/bcz_paper_target_crosswalk_20261020/report.json`已区分本行10个原生槽与未来观测帧，已有23条历史训练演示、33,320个原生目标数值往返记录。此次原样复用，没有再拟合、重读那些记录或把它们冒称当前全部BC-Z数据验收。

原生10槽的空间候选为 `p_t + xyz_residual[t,k]`，旋转为将 `axis_angle_t + residual[t,k]` 转成姿态，再相对同一个输入姿态编码。它不是把各槽残差累加，也不是将轴角残差直接作为Euler或相对四元数。该数值定义尚不解决每槽对应哪个执行时刻。

## 当前决策与后续顺序

保持现有训练和评估文件；不静默删掉某一来源，不用实际到达状态冒充缺失的期望目标，不把RPY、轴角残差与相对四元数混用。新控制目标训练版本仍未准入。

原生目标转换成功说明该工程接口路线可行；这些来源缺口说明它还不能直接成为主模型的新监督。完整源动作恢复需要原始desired_state/采集配置、精确导出行配对或维护者说明；若拿不到，应该带这张具体差异表与老师确认可接受的来源转换/适配假设，不继续靠长训练掩盖。

与此同时，原计划中“现有主模型在四来源独立验证演示上解码后是否优于不动”的学习诊断仍未完成。它不需要先重建控制目标，也不涉及训练拟合；可使用固定、少量已用验证窗及现有权重区分源内学习表现与目标域执行问题。该项尚未运行，不把此处字段核对算作源内泛化成绩。最终13条件任务清单保留，批量实验继续暂停。
