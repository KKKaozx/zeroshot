下表是x0/sample，不是epsilon；位移幅度用各窗口有效步的平方能量等窗平均再开根号（RMS），不是平均欧氏误差。

方向对齐是按窗口等权、有效步和采样平均的预测·目标内积，除以两者能量平方根；1表示整体完全同向，接近0表示该批窗口的整体对应很弱。它不是每窗夹角均值，不能解释为所有样本都随机或都反向。

Bridge的总体位移量级已接近目标，因此不能仅凭幅度过大解释主要误差，也不能据此说每个窗口幅度都正确。方向对应在已见训练窗和验证窗均弱。x0三次采样的差异只占Bridge验证位置平方误差约12.66%；三次位置预测均值的误差占87.34%，仍是不动平方误差的1.943倍。训练窗相应为83.61%/1.611倍。因此三次采样波动并不足以解释失败；这里的均值只用于误差分解，没有作为新的采样策略或训练seed证据。

有效未来第1步，Bridge验证x0位置误差0.29831，不动0.18745；第4步1.28686/0.75261，第8步1.86459/1.22392。第16步只有32个有效窗口，2.13335/1.45750，不能把不同步的误差增幅当作同一群体严格比较。最早一步已有误差劣势，说明观察到的问题不限于长未来预测的不确定性。位置均为归一化记录单位，没有新增物理标定。
