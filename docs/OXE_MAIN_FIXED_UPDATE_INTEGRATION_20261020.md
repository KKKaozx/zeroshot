# 主训练入口：固定更新与完整续跑接线

2026-10-20。完成原计划中的工程接线，没有提交真实训练或产生新的泛化成绩。

## 实际改动

`code/train.py`仅在显式指定`--total-updates`时调用`code/step_training_runner.py`。新分支复用现有Dataset、RobotAdapterModel、tokenizer、collator、带掩码的`policy_loss`及验证损失函数。未修改Adapter、CLIP、扩散网络或动作转换实现。

- 固定总更新数U；分段停止不重开U或学习率周期。旧epoch参数在新模式不生效，显式更改会被拒绝。保留短尾批次，支持已有的普通打乱和按schema均衡有放回抽样；没有替正式方案选定来源比例。
- 每次优化成功后提交游标、设置下一步学习率，再存盘。保存可训练权重、AdamW、更新数、当前抽样顺序/游标/生成器、Python/NumPy/Torch CPU/CUDA随机状态、历史及语言计数。
- 合同绑定源文件内容SHA、实际窗口身份与完整分区、冻结骨干参数/缓冲区摘要、模型配置、tokenizer词表/编码规则、语言库、源码和运行设置。初始化/加载后最后恢复随机状态。冻结骨干不重复存入训练权重。
- 语言抽样时钟使用保存的遍历编号和全局更新数，不因重启重置。真实四条件仍须提供训练专用的已审阅语言库。
- 验证在固定全局间隔执行并保护训练随机状态，分段提前停止不额外验证。这里只记录验证损失，不选最好权重，不读取test目标，不给出动作/任务成功率。每批保存有效监督维度计数；正式来源权重和损失口径仍需冻结。

当前限定单进程、workers=0、FP32、无AMP/梯度累计。新输出`latest_step.pt`、`step_report.json`与旧格式隔离，拒绝混用旧恢复、迁移、拟合诊断。新运行要求空目录；恢复只可写空目录或自身检查点目录。

结构必须显式选择compact或multiscale；后者将现有通道256/512/1024、时间嵌入128、核5写入实际配置。这消除了“模型类支持但CLI未选择”的歧义，不代表正式架构已选定或通过真实预检。

## 验收

从真实`train(parse_args(...))`入口运行，用合成数据、微型冻结编码器/可训练头及合成tokenizer替换重型依赖；其余训练循环、masked loss、AdamW、学习率、分区检查和存取使用生产代码。**不是CLIP/机器人训练或真实四源数据资格验收。**

| 项目 | CPU | CUDA |
| --- | ---: | ---: |
| 两种采样×两种调度×两个种子×六种中断位置 | 48条完全一致 | 48条完全一致 |
| 四种语言条件多次中断接线 | 4条完全一致 | 4条完全一致 |
| 非法恢复/配置拒绝 | 15项 | 15项 |

比较最终权重、优化器、采样/RNG状态、完整历史，以及实际前向的噪声、时间步、输入、预测。覆盖短尾、遍历边界和多次中断；恢复前故意消耗随机数。含平面/缺失维度掩码，test的`__getitem__`从未调用。语言审阅记录是明确标注的合成fixture，不能用作真实语言库。

拒绝项包括改变U、批量、学习率/预热、结构、冻结权重、tokenizer、分区、同大小/mtime但不同内容的源文件，以及混用旧恢复、workers>0或漏选新模式。拒绝过程中没有解码样本。

另以实际本地缓存的CLIP tokenizer验收当前Transformers新后端合同序列化，未加载CLIP权重或联网下载；也支持旧slow tokenizer。所有旧函数和参数解析器剔除新增分支/参数后，与接线前AST完全相同。旧epoch语义保留。

证据：[CPU报告](../reports/step_main_runner_20261020/report.json)、[CUDA报告](../reports/step_main_runner_cuda_20261020/report.json)、[脚本](../scripts/check_step_main_runner_20261020.py)。各报告含当次源码SHA/快照、合成检查点及执行日志。逐位一致结论限相同环境的上述路径；没有证明任意GPU、非确定性核、多worker或真实大模型均可逐位重放。

## 使用边界

| 新参数 | 含义 |
| --- | --- |
| `--total-updates U` | 启用新模式，固定全程预算 |
| `--split-manifest PATH` | 已验证、覆盖全部窗口且按完整轨迹隔离的清单 |
| `--step-diffusion-architecture compact或multiscale` | 显式结构选择 |
| `--stop-after-updates S` | 本段停止的全局位置，S≤U |
| `--step-resume PATH` | 完整新格式检查点；U及训练合同必须一致 |
| `--checkpoint-every-updates N` | 存盘间隔 |
| `--validate-every-updates N` | 全局验证损失间隔 |
| `--warmup-updates W` | 固定时域内预热长度 |

此处不编造真实预算或生成提交脚本。这不是历史Bridge泛化根因诊断。Bridge207558、Push-T214273及独立包不变。来源物理单位/时间规则、全局组到实际窗口绑定、正式架构/预算/来源采样、真实语言库及最终资源预检仍未完成；`training_ready=false`。
