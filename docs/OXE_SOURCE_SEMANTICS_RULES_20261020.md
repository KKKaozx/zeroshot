# 混源夹爪输入与Language Table平面监督规则

2026-10-20。新增独立`code/oxe_source_semantics.py`及检查脚本，未修改旧数据加载器、模型、主损失或既有训练路径。Push-T214273、Bridge207558保持不变。此次无模型、优化器、图像解码、拟合或泛化实验。

## 夹爪输入：上一命令与可用性分开

新规则使用两维输入`[上一条明确的开正命令, 是否已知]`：打开`[1,1]`，关闭`[-1,1]`，缺失`[0,0]`。缺失的0不是“半开”或真实物理状态。它表示记录中的命令，在未核实硬件回执前不宣称是实际执行状态；实测开度不进入这两个字段。

| 来源 | 只取当前观测之前的内容 | 不明确时的处理 |
| --- | --- | --- |
| Bridge | 前一原生action中的明确二值开度端点，开为1、关为0 | 连续/带偏移值不裁剪、不阈值化、不从未来反填，也不沿用更早命令冒充当前命令；标缺失 |
| BC-Z | 前一观测的`target_close`首个命令，闭合为1，反号得到开正编码 | 初始无先前命令标缺失；非二值目标拒绝，不用`sensed_close`替代 |
| Fractal | 向前扫描此前相对夹爪动作；正值关闭、负值打开、死区保持已知命令 | 第一次有效命令之前始终缺失，不用未来第一次切换反推输入初态 |
| Language Table | 无夹爪命令 | 全部缺失，不默认打开 |

这与可使用完整演示转换监督标签的函数有区别：输入特征不能借助未来信息。`command_features_before_rows`在消费动作t之前输出观测t的特征；没有使用最后一行终止动作。此phase只用于已经确定“观测在同一行action之前”的来源，不能套到LIBERO post-step数据。

## Language Table：不能伪造朝向，也不能简单旋转二值mask

本地`features.json`的观测只有`effector_translation`、`effector_target_translation`、`instruction`和`rgb`，没有记录末端朝向。作者的[环境实现](https://github.com/google-research/language-table/blob/main/language_table/environments/language_table.py)使用平面末端位置；其[仿真常量](https://github.com/google-research/language-table/blob/main/language_table/environments/constants.py)包含固定工具朝向，但这不证明真实机器人采用相同标定。此次未获得实机工具朝向的可靠依据，主训练接入仍未放行。

若之后获得输入时刻的真实旋转`R_source_from_tool`，不必填造未记录的z、旋转或夹爪标签。应在源坐标的两个可观测方向计算监督：

`预测平面位移 / s = R_source_from_tool[:2, :] × 预测工具坐标位移`

这里s为既有位置归一化尺度。一般旋转会将工具xyz混合，不能把源坐标中的“只知道xy”简单解释为工具坐标中的`[1,1,0]`mask。新增投影核只惩罚已观测平面误差，沿未观测方向改变预测不会产生损失或梯度；不引入其他六维的假标签。

45度旋转的合成检查验证了投影与未观测方向梯度，错误旋转矩阵、缺少标定依据或用sim标定替代real均拒绝。这是几何/梯度检查，不是真实标定验收。配置中的审阅文字不能自动证明其物理真实性。

投影损失接受的是干净动作x0。若采用epsilon目标，需先由带噪动作、时间步和噪声预测恢复x0，再定义对应训练损失；不能直接拿epsilon与实测xy位移比较。本核尚未接入主`policy_loss`。

## 下一项与明确限制

后续进度：两维输入现已作为默认关闭的新模式接入三个3D来源的实际解析器、主模型/训练/评价和LIBERO回调，旧模式一致性及合成更新检查通过。详见[主链路接入记录](OXE_COMMAND_INPUT_CHAIN_20261020.md)。下面是该接入前的阶段说明；Language Table标定与投影损失仍未接主训练。

夹爪规则和缺失编码已经有独立实现，下一项是作为新混源模式接入数据/模型/评价链：模型输入投影需显式支持2维，缺失时的评价基线和监督mask要一致；旧1维模型与旧checkpoint路径保留。不能把新2维特征塞入旧1维输入或事后改写旧checkpoint语义。

Language Table接入仍需要真实坐标依据；没有该依据时，要么补到可靠标定，要么对全部来源明确修订统一动作表示/监督结构，单列新模型协议。不能静默删去这个来源，也不能用单位旋转凑齐四来源。目标时间、完整数据划分、固定训练预算同样仍待落实。

这些是新混源基线的接入规则，不是Bridge历史泛化根因，也没有新性能成绩。
