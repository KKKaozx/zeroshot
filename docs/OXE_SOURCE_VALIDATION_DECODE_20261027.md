# 当前四来源模型的源验证动作解码结果

**固定小样本中，seed42四来源模型的位置预测均未超过不动基线。** 这项结果发生在原OXE源验证分布，没有经过LIBERO动作转换或物理控制。因此，目前观察到的问题不能仅归因于跨机器人控制接口；模型的源内预测及其训练/采样对应也需要检查。它不证明整个验证集的精确差距，不确定唯一根因，也不替代最终任务成功率。

## 使用的模型与样本

使用已验收的四来源无增强seed42最终65,536更新模型，不挑checkpoint，不测试seed43以选更好结果；原学习张量SHA`2295d8ad...66d`和冻结身份`91175b04...1999`在前后均完全一致。沿原主加载器、图像预处理、tokenizer、get_context_vector及sample，恢复已绑定的两个平台相关固定buffer后，DDPM100步、原beta/epsilon配置、FP32、eval/inference模式执行。

这是当前主模型，不是旧Bridge207558专用模型。数据规模、角色划分及模型不同；不能将旧Bridge留出优于不动的结果套到这份四来源模型，也不能用此次结果抹掉旧实验。

对每来源按固定元数据SHA排序选8个不同origin/content组，各取一个已有演示的中间窗口，共32窗口。选择在读取预测结果前冻结，没有按动作幅度、夹爪变化或误差选样；训练与验证源组无交集。这些是既有开发验证角色，之前用于验证loss，不冒称新的盲测。每窗只做一个预定随机噪声抽样，不挑抽样种子。

## 复核和资源

原预测、目标、mask、输入特征、逐窗指令和选择身份全部保留，32张输入缩略图已查看。独立CPU复算核对：目标及mask逐元素等于绑定验证缓存；由缓存的原始观测位姿重新推导位置标签，最大差1.04e-8原记录单位；独立float64位置统计最大差5.66e-8归一化单位，SciPy旋转角复算最大差3.56e-11度。它们是数值复核差，不是模型预测误差。

本轮32窗解码完成、无异常；总墙钟65.16秒，其中推理阶段26.61秒，峰值reserved约2.15GiB。0优化更新、0仿真、0正式LIBERO回合，权重和冻结编码器未变；没有生成新标签或改变动作定义。

## 目前可以得出的结论

1. 当前模型在这些独立源验证演示上尚未建立相对不动的姿态预测优势；这不是单纯的LIBERO坐标转换误差。
2. 验证loss约0.125不等于预测位姿误差，更不等于控制成功。训练及evaluate_loss采用随机加噪目标的去噪损失；这里从纯噪声完整采样并按原位姿标签评价，两项衡量的能力不同。
3. 实际源码中，训练夹爪分支接收真实干净姿态，完整采样时夹爪分支接收生成姿态。这是需要纳入后续诊断的条件差异，不是已证实的位置错误根因；位姿生成器并不依赖夹爪头输出。
4. 原生期望目标工程转换成功和本轮源内预测不足可以同时成立；两者分别约束执行层与学习层。现在不应只改执行器，或仅凭换监督目标就重训13组。
