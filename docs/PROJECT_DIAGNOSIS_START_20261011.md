# 项目排查起点与论文复现边界（2026-10-11）

## 修正排查起点

上一轮建议先用单窗口证明扩散能记住目标，没有充分利用已存在的完整冻结上下文成功实验。原始 reports/bridge_full_x0/final_metrics.json 三个采样种子训练位置误差分别为 0.210392、0.210365、0.210378 cm，旋转误差约 0.954°。diagnostics/full_x0/run_full_fit.py 确认评估使用纯噪声开始的完整 100 步采样，不是给真实动作加噪后的恢复指标。

这证明当时单任务、固定上下文、紧凑解码器与对应优化配方的训练位姿可记忆；不证明当前五任务联合模型正确，也不证明夹爪或泛化通过。首先比较成功与失败的路径，不重复把已有的能力当作完全未知。

- U-Net 同配置结构可映射；小宽度实际前向/梯度一致。位姿 MSE 同目标的合成检查一致。完整实际宽度训练性能不是由这项数值检查证明的。
- 实际 DDPM 更新与官方 scheduler 的数值对照通过。
- 官方两帧图像与数值 agent_pos 条件；项目单帧 CLIP/语言融合条件，没有把当前末端位姿输入位姿 context。官方视觉编码器不是冻结 CLIP/Adapter。
- 官方二维控制动作与项目三维未来到达位姿不同；Push-T 没有语言和夹爪，不存在可直接搬来的官方夹爪或 CLIP Adapter 模块。
- EMA、位置尺度、预测目标已在 Bridge 做过受控实验，未解决完整生成失败。暂不重复。

## 建议顺序与停止条件

1. 先核实早期成功实验的数据缓存、源文件、模型和指标是否还可获得，确认当前版本加载/采样与旧正对照接口之间的差异。这一步先读文件，不下载新数据、不提交全量训练。不得假定集群旧缓存仍在。
2. 用当前训练划分中的预先固定小集合建立两组同起点对照：固定 Adapter 上下文只训练位姿解码器，与允许 Adapter 随位姿损失联合训练。两组共用相同图像、动作、初始权重、batch、每窗口抽取量、学习率、噪声/时间步和完整 100 步评估。两组均冻结夹爪头，暂时分离位姿拟合与夹爪优化。这是阶段诊断，不是改变最终导师要求。
3. 训练拟合以纯噪声完整生成的 cm / 度、终点和逐窗口指标判读，不能以训练去噪 loss、给真实轨迹加噪的恢复误差或三种采样种子的均值替代。
4. 若固定上下文组明显好、联合组差，优先查条件漂移、Adapter 优化与训练/评估模式；不能立即宣布 Adapter 实现错误。若两组都好，再逐步增加窗口/任务，找拟合开始失败的规模。若两组都差，先查是否有足够可区分条件及优化诊断，必要时用显式窗口标识条件作隔离；预算内失败不证明模型永远学不会。
5. 开跑前固定预算、评价检查点、拟合阈值和下一步分支。可用既有早期位置≤0.5 cm、旋转≤5°作为诊断阈值；同时报告逐窗口通过比例，不能把均值通过称为所有窗口拟合。预算耗尽未通过时先记录结果，不自动无上限加轮数。

这里还没有实现或执行新的对照。建议优先解决训练集生成，再考虑数值状态/历史条件、原生动作接口以及正式仿真。训练拟合通过不等于泛化通过，更不等于导师要求的 LIBERO/CLIPort 任务成功、增强条件、训练种子与消融已完成。
