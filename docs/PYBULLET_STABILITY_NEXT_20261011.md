# 固定场景正对照后的下一步：状态覆盖对照

当前已经证明小样本拟合与固定训练场景物理抓取可以通过。接下来检验闭环稳定性，不改变网络结构、扩散目标、采样器或机器人控制接口。

## 已实际核查的缺口

[状态覆盖审计](../reports/pybullet_fixed_grasp_policy_20261011/state_coverage_audit.json)读取真实保存的训练与执行数组。8个窗口中，没有一个窗口的16个未来位移都小于1mm；最后一个训练观测仍处在上升过程中，而不是已经停止的保持状态。演示本身有保持片段，但它太短，未形成当前选窗规则需要的完整16步保持窗口。

训练当前夹爪输入范围约[-0.01045,1.00000]：夹住4cm方块时开度约40mm，对应编码接近0。真实闭环空夹时开度接近0mm，输入达到约-1；三个回合分别有2、3、1次重规划输入超出训练开度范围。这是实际状态覆盖差异，还未证明它是空夹或重新打开的唯一原因。

## 第一轮仅改变保持状态样本

将同一物理采集演示的末端保持延长16个控制周期，保留原91帧；必须先核对原始前缀图像、末端位姿、实测开度和命令与原记录一致，避免把采集轨迹变化混进比较。增加一个真正静止且双指夹持的16步未来窗口，不用未执行的重复末帧伪造未来标签。

做两个从相同初始化训练的9窗口组：

- 对照组：原8窗口＋重复原起点74的窗口。
- 保持组：原8窗口＋新增的纯保持窗口。

两组均使用batch9、1000次更新、相同初始参数、Adam1e-4、dropout0.1、相同加噪种子、原始联合损失和原生100步采样。第9个训练窗口是唯一改变的数据项。两组保持相同总更新数和每次窗口数；对照组重复样本是显式采样权重，不冒充第9条独立演示。不能直接用此前batch8的报告充当这轮配对对照。

固定初始场景、相同3个采样种子、相同28次重规划，每次执行4动作。依旧由网络独立驱动，记录实际双指接触、物体高度、目标动作与开度，保留无辅助绑定的抓取判据。

预先新增停位检查：最后2秒实际物体高度与采集演示保持高度的绝对差始终不超过2cm；这段高度最大值减最小值不超过1cm，并保持双指接触。同时报告连续数值，不把单次布尔值当作充分结论。若小样本拟合本身未过门槛，不据闭环结果判断状态覆盖假设。

若保持组更稳定且仍能抓取，支持“缺少保持状态监督影响停位”的局部解释；若没有改善，保留失败证据，进一步检查新观测下预测的残余位移与控制误差，不再无依据增加训练轮数。

## 后续顺序

保持对照结束后，再单独处理闭合前与空夹后的输入状态覆盖，使用物理采集的正确动作监督。保持架构和控制器不变，禁止靠手写闭合规则掩盖模型错误。固定场景的抓取时序与保持稳定后，才小幅改变方块位置测新场景能力。这三项结论分别报告，不能用固定场景3/3代替泛化通过。
