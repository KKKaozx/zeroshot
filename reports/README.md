# Selected evidence

For the current interpretation, start with [the 15 October status](../docs/STATUS_20261015.md).
The update includes numerical diagnostic reports, source snapshots, and selected
plots. Full new update streams and numerical run reports above 1 MiB remain
outside Git, alongside checkpoints, NPZ prediction arrays, raw dataset image
collections, and transfer archives. Some historical documents link
to those retained artifacts; their absence from Git is intentional. A Git clone
alone is not a complete reproduction environment or a backup of model weights.

These small numerical reports are copied without changing their contents. `evidence_manifest.json` records their SHA256 checksums. Historical reports contain machine-specific paths and scope statements valid at their creation time; see the current progress document for the final interpretation. No raw RGB data or checkpoint is included.
